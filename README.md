# Infravanta Home

Your home. Your money. Better decisions.

| Folder | What it is |
|---|---|
| [frontend/](frontend/) | Next.js, TypeScript and Tailwind CSS app |
| [backend/](backend/) | Python FastAPI service |
| [.github/workflows/](.github/workflows/) | CI checks and tests |

## Run the frontend

```powershell
cd frontend
npm install
npm run dev
```

Then open http://localhost:3000.
